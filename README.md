# NM INOVATION — Digital Systems

A modern full-stack digital systems platform built for **NM INOVATION**, combining a React/Vite frontend with an Express.js backend and MongoDB database.

The platform is designed to help businesses move from traditional/local operations to structured, scalable digital systems through business inquiries, digital audits, operational system planning, insights, and case studies.

## 📌 About The Project

NM INOVATION is a digital technology platform focused on helping businesses build and improve their digital infrastructure.

The application provides:

- Business inquiry submission
- Digital maturity/audit assessment
- Operational system planning
- Business insights
- Case studies
- API health monitoring
- MongoDB-backed data storage
- Secure API endpoints
- Rate limiting
- Security headers
- Responsive modern frontend

The project is built as a full-stack JavaScript application and is designed to be deployable as a single application.
